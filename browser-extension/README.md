# PiliPlus 推送（浏览器扩展）

把电脑浏览器里正在播放的 Bilibili 视频推送到局域网内的 PiliPlus 设备（手机/平板），接收端确认后接着当前进度播放。

## 前置条件

- 目标设备安装的 PiliPlus 版本需要包含 HTTP 推送接口（端口 26982，v2.1.0 之后的版本）。
- 设备已开启「设置 → 其它设置 → 接收设备推送」。
- 电脑与设备在同一局域网。

## 安装

1. 打开 Chrome/Edge，访问 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录（`browser-extension`）。

## 使用

1. 在浏览器打开一个 B 站视频页（普通视频或番剧均可）。
2. 点扩展图标，确认已识别出当前视频标题。
3. 第一次使用：在输入框填写设备 IP（手机 PiliPlus 的局域网 IP，可在手机「设置 → 关于」或路由器后台查看），点「添加并检测」；检测成功后设备会保存在列表里。
4. 点设备旁的「推送」；手机上会弹出「电脑浏览器 推送了视频」，点「播放」即可接着进度播放。

## 说明

- 设备发现：浏览器扩展无法使用 UDP 广播，因此需要手动填写设备 IP（会保存在本地，不会上传）。
- 支持的页面：普通视频（`/video/BV...`）与番剧（`/bangumi/play/...`）；直播暂不支持。
- 推送内容只包含视频标识与进度，不经过任何第三方服务器，纯局域网直连。
